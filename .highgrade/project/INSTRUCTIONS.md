# Kazankin Project local instruction

Статус: HG-0001 остаётся прежним контрактом и не синхронизирован с текущей реализацией. По прямому разрешению владельца активны пять слайдов; «Отзывы» показывает один RU/EN-моковый пример, заметно помеченный как нереальный, а раздел «Этапы» — девять аккордеонов. Детали этапа открываются поверх сетки без сдвига карточек, фон плавно затемняется; при высоте viewport до 700 px детали появляются в центральной панели. Заголовок этапов: «ЧЕМ Я МОГУ ВАМ ПОМОЧЬ.» / «WHAT I CAN HELP WITH.». Эти изменения внесены без High Grade CLI и без обновления спецификации; перед следующей формальной задачей синхронизировать контракт штатным совместимым инструментом.

<a id="проект-и-владельцы"></a>

## Проект и владельцы

- **Назначение:** Разработка сайта-портфолио видеомонтажёра Дмитрия Казанкина («KAZANKIN ВИДЕОМОНТАЖ») по материалам из `Referens/`. Текущая публичная подача — монтаж и постобработка; съёмку выполняет клиент или его оператор.
- **Архитектура и стек:**
  - Методология Feature-Sliced Design (FSD: `app`, `pages`, `widgets`, `features`, `entities`, `shared`).
  - React, React Router, TypeScript, `clsx`, CSS Modules, Storybook, библиотека анимаций Motion.
  - Атомарное расщепление на примитивные лейаут-компоненты (`Container`, `Section`, `Heading`, `Text`, `Block`, `Stack`, `Grid`).
  - Все переиспользуемые стили без исключения выносятся в CSS-переменные в `:root`.
- **Язык проекта:** Пользовательские документы, спецификации, коммиты и документация ведутся на русском языке. Сайт реализует полную двуязычность (RU / EN).
- **Владельцы знаний:**
  - Цель, описание продукта: [README.md](../../README.md)
  - Правила для агентов: [AGENTS.md](../../AGENTS.md)
  - Дизайн-система (токены цветов, типографика): [docs/DESIGN_SYSTEM.md](../../docs/DESIGN_SYSTEM.md)
  - Архитектура приложения: [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md)
  - Инженерный регламент и команды: [docs/DEVELOPMENT.md](../../docs/DEVELOPMENT.md)
  - Реестр контекста: [documents.json](documents.json)
- **Спецификации:** каталог `specs/` в формате native JSON (v5). Требования и сценарии (Given/When/Then).

<a id="ключевой-функционал-и-навигация"></a>

## Ключевой функционал и навигация

- **Категории:** Hero (видеофон из S3 `KPV/hero/`, слоган «ВЫ СНИМАЕТЕ. Я СОБИРАЮ ИСТОРИЮ.» и центральная кнопка «Смотреть работы ↗»), Работа (горизонтальный слайдер, автоплей видео при открытии модалки, FastStart веб-поток через HTTP 206), Отзывы (двуязычный моковый пример с заметной меткой «не реальный отзыв»), Этапы (девять карточек-аккордеонов), Связаться.
- **Этапы:** раскрытые детали накладываются поверх сетки, не сдвигая карточки; фон плавно затемняется, панель анимированно раскрывается. При высоте viewport до 700 px выбранный этап показывается центральной панелью. Учитывайте `prefers-reduced-motion`; внутреннюю вертикальную прокрутку слайда не добавлять.
- **Заголовок этапов:** RU «ЧЕМ Я МОГУ ВАМ ПОМОЧЬ.»; EN «WHAT I CAN HELP WITH.»
- **Полноэкранная навигация:** пять слайдов занимают 100vh / 100dvh и переключаются дискретно колесом, touch-жестом, клавиатурой, шапкой и SideDots. Видимые полосы прокрутки скрыты; карусель работ прокручивается горизонтально отдельно.
- **Прилипающая шапка (Fixed):** активный пункт соответствует индексу текущего слайда.
- **Локализация (i18n):** 100% перевод всех элементов страницы при смене языка RU/EN.
- **Доступность и SEO:** a11y атрибуты для скринридеров, семантика, Schema.org JSON-LD.
