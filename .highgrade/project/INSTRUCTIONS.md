# Kazankin Project local instruction

Статус: HG-0001 остаётся прежним контрактом. По прямому разрешению владельца интерфейс обновлён без High Grade CLI; фактическая композиция теперь включает четыре слайда и не выводит отзывы. Перед следующей формальной задачей синхронизировать контракт штатным совместимым инструментом.

<a id="проект-и-владельцы"></a>

## Проект и владельцы

- **Назначение:** Разработка сайта-портфолио видеомонтажёра Дмитрия Казанкина («KAZANKIN ВИДЕОМОНТАЖ») по материалам из `Referens/`. Текущая публичная подача — монтаж и постобработка; съёмку выполняет клиент или его оператор.
- **Архитектура и стек:**
  - Методология Feature-Sliced Design (FSD: `app`, `pages`, `widgets`, `features`, `entities`, `shared`).
  - React, React Router, TypeScript, `clsx`, CSS Modules, Storybook, библиотека анимаций Motion.
  - Атомарное расщепление на примитивные лейаут-компоненты (`Container`, `Section`, `Heading`, `Text`, `Block`, `Stack`, `Grid`).
  - Все переиспользуемые стили без исключения выносятся в CSS-переменные в `:root`.
- **Язык проекта:** Пользовательские документы, спецификации, коммиты и документация ведутся на русском языке. Сайт реализует полную двуязычность (RU / EN).
- **Владельцы знаний:**
  - Цель, описание продукта: [README.md](../../README.md)
  - Правила для агентов: [AGENTS.md](../../AGENTS.md)
  - Дизайн-система (токены цветов, типографика): [docs/DESIGN_SYSTEM.md](../../docs/DESIGN_SYSTEM.md)
  - Архитектура приложения: [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md)
  - Инженерный регламент и команды: [docs/DEVELOPMENT.md](../../docs/DEVELOPMENT.md)
  - Реестр контекста: [documents.json](documents.json)
- **Спецификации:** каталог `specs/` в формате native JSON (v5). Требования и сценарии (Given/When/Then).

<a id="ключевой-функционал-и-навигация"></a>

## Ключевой функционал и навигация

- **Категории:** Hero, Работа (горизонтальный слайдер), Этапы (статичные карточки), Связаться. Унаследованный review-слайс не подключён к актуальной странице.
- **Полноэкранный скролл:** четыре слайда занимают 100vh / 100dvh и переключаются дискретно колесом, touch-жестом, клавиатурой, шапкой и SideDots. Внутренняя прокрутка длинной секции сохраняется.
- **Прилипающая шапка (Fixed):** активный пункт соответствует индексу текущего слайда.
- **Локализация (i18n):** 100% перевод всех элементов страницы при смене языка RU/EN.
- **Доступность и SEO:** a11y атрибуты для скринридеров, семантика, Schema.org JSON-LD.
