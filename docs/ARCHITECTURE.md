# Архитектура проекта «KAZANKIN» (Feature-Sliced Design)

Проект построен по методологии **Feature-Sliced Design (FSD)** версии 2.1 с компонентным дроблением на примитивные лейаут-компоненты, полной адаптивностью для мобильных устройств и сборкой из них интерфейсных блоков.

---

## 1. Стек технологий

- **Фреймворк:** React 19 / 18 + TypeScript
- **Маршрутизация:** React Router 7 / 6
- **Стилизация:** CSS Modules + `clsx`
- **Дизайн-система:** Строгие CSS-переменные (`:root` / `variables.css`)
- **UI-компоненты и документация:** Storybook 8
- **Анимации:** Motion (Framer Motion)
- **Интернационализация (i18n):** Встроенный типизированный контекст/модуль локализации (RU / EN)
- **Доступность и SEO:** Семантическая разметка HTML5, WAI-ARIA, структурированные данные Schema.org JSON-LD
- **Адаптивность:** Mobile-First подход, поддержка экранов от 320px до 4K, тач-таргеты 44px+

## 3. Принцип компонентного дробления (Layout Components First)

Все элементы сайта строятся из примитивных лейаут-компонентов:
1. **Никаких сырых `div` с хаотичными стилями:** вместо них используются `<Block>`, `<Stack>`, `<Grid>`, `<Container>`, `<Section>`.
2. **Типографика через `<Heading>` и `<Text>`:** гарантирует единые масштабы, трекинг и адаптивный clamp-кегль.
3. **Составные виджеты компонуются декларативно:**
   ```tsx
   <Section id="stages" fullpage>
     <Container>
       <Stack gap="xl">
         <Heading level={2} overline="02 / ЭТАПЫ РАБОТЫ">
           {t('stages.title')}
         </Heading>
         <Grid cols={{ sm: 1, md: 2, lg: 2 }} gap="md">
           {stages.map((stage) => (
             <StageCard key={stage.id} stage={stage} />
           ))}
         </Grid>
       </Stack>
     </Container>
   </Section>
   ```

## 4. Полноэкранный скролл и Scroll-Spy шапки

1. **Fullpage Snap на десктопе:**
   - На экранах от `1024px` каждая секция (`<Section fullpage>`) имеет высоту `100vh` и поведение `scroll-snap-align: start`.
   - Внешний скролл-контейнер управляет плавным переходом между секциями без рывков.
2. **Scroll-Spy:**
   - Хук `useScrollSpy` на базе `IntersectionObserver` определяет, какая секция занимает более 50% экрана.
   - Активный идентификатор (`activeId`) передаётся в `<Header>`, где соответствующая ссылка получает выделение цветом `--color-light-beige` и индикатором.

## 5. Двуязычная локализация (i18n)

- Словари переводов (`ru.json`, `en.json`) охватывают **100% контента**:
  - Названия категорий меню и интерфейсные кнопки.
  - Заголовки, описания, слоганы.
  - Карточки работ и метаданные.
  - Детальные описания этапов в раскрывающемся аккордеоне.
  - Все отзывы клиентов (имя, проект, текст отзыва).
  - Контактные данные и уведомления.
- Выбранный язык синхронизируется с атрибутом `<html lang="...">` для скринридеров и поисковых систем.

## 6. Архитектура адаптивности для устройств с меньшим разрешением

1. **Безопасный мобильный скролл (Anti-Overflow):**
   - На экранах `< 1024px` фиксированная высота `100vh` заменяется на `min-height: 100dvh` (Dynamic Viewport Height).
   - Секции с объёмным содержимым (раскрытые этапы, список отзывов) получают `overflow-y: auto`, что полностью исключает обрезание контента снизу на смартфонах с небольшой высотой экрана (напр. iPhone SE 568px/667px).
2. **Мобильное меню (Header Drawer):**
   - При ширине экрана `< 768px` навигация сворачивается в гамбургер.
   - По клику открывается боковой/полноэкранный Drawer со списком категорий и кнопкой смены языка.
   - Реализована блокировка скролла фона (`body { overflow: hidden }`), закрытие по клику на фон, на ссылку или по кнопке `Escape`, а также циклический захват фокуса (Focus Trap) для скринридеров.
3. **Тач-интерфейс и доступность:**
   - Все интерактивные элементы (кнопки, плашки этапов, ссылки) имеют минимальную область нажатия `44x44px`.
   - Отсутствуют зависимые от `:hover` критические действия — все функции доступны по одиночному тапу.

## 7. Системные оптимизации и визуальный харнес

1. **Мгновенный тёмный холст (Zero-Flash FOUC Prevention):**
   - Инлайн критический CSS в `<head>` теге `index.html` с декларациями `background: #100D0C !important` и `color-scheme: dark`.
   - Гарантирует отсутствие белых вспышек при любой первичной загрузке или обновлении страницы.
2. **Изолированный аккордеон этапов:**
   - CSS Grid контейнер настроен с `align-items: start;`, а карточки этапов — с `align-self: start; height: fit-content;`.
   - Раскрытие одного этапа изолировано и не приводит к паразитному растяжению соседней карточки в строке.
3. **Диагональный сухой мазок RDR2:**
   - Векторный контур `public/rdr-brush.svg` со скошенными ворсинками щетины кисти (chisel cut) под углом `-1.5°` без закругления в капсулу/овал.
4. **Симметричная типографика RU / EN:**
   - Единый шрифт `Inter` (веса от 400 до 900 Black) гарантирует строгое оптическое равенство размеров, x-height и ширины символов для кириллицы и латиницы.
