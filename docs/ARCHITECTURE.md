# Архитектура KAZANKIN

Лендинг реализован на React 18 и TypeScript в структуре Feature-Sliced Design. Текущая активная страница собрана из пяти экранов; общие токены и UI-примитивы находятся в `shared/`.

## Слои и активные виджеты

```text
src/
├── app/                         # Инициализация приложения и провайдеры
├── pages/landing/               # Пятислайдовая композиция и трек
├── widgets/
│   ├── header/                  # Навигация, язык и мобильное меню
│   ├── hero/                    # Первый экран
│   ├── works/                   # Карусель обложек и модальный видеоплеер
│   ├── reviews/                 # Третий экран: явно помеченный моковый пример
│   ├── stages/                  # Девять этапов, две группы
│   ├── contact/                 # Финальный призыв связаться
│   └── footer/                  # Бренд и география
├── features/
│   ├── swipe-navigator/         # Переходы между слайдами и боковыми точками
│   ├── language-switcher/       # RU / EN
│   └── stage-accordion/         # Одновременно раскрытый этап/закрытие предыдущего
├── entities/
│   ├── work/                    # Данные и карточка работы
│   ├── stage/                   # Типы, данные и карточка этапа
│   └── review/                  # Карточка мокового примера и оценка 1–5
└── shared/
    ├── lib/i18n/                # Типы, переводы и контекст RU / EN
    ├── styles/                  # Глобальные стили и токены
    └── ui/                      # Section, Container, Heading, Text, Grid, Button, Badge
```

`src/pages/landing/ui/LandingPage.tsx` задаёт пять активных слайдов в порядке Hero, Works, Reviews, Stages, Contact и передаёт текущее положение в шапку и боковую навигацию. `ReviewsSection` — третий экран, сразу после Works; он показывает один двуязычный моковый пример с рейтингом по шкале 1–5 и явной пометкой, что это не отзыв клиента. После получения материалов пример заменяется реальными отзывами; средние оценки и метрики не выдумываются.

`HeroSection` получает признак активного слайда от `LandingPage`: видео остаётся смонтированным, пока не включён `prefers-reduced-motion`, но воспроизводится только на первом экране. При переходе на другой слайд оно ставится на паузу, а при возврате продолжается с сохранённой позиции. Для ширины до 767 px выбирается `hero-mobile.mp4`, для более широкого экрана — `hero-desktop.mp4`; оба ролика загружаются по публичным URL из внешнего S3-хранилища, локальных копий в репозитории нет. Видео без звука, с размытием и затемняющим слоем.

## Слайдовая навигация

`useDiscreteSwipe(totalSections)` из `src/features/swipe-navigator/model/useDiscreteSwipe.ts` управляет индексом текущего экрана. `LandingPage` применяет `translate3d` к треку на высоту `100dvh`; общее число экранов передаётся как пять.

Хук обрабатывает вертикальное колесо мыши, вертикальный touch-жест и клавиши прокрутки; ссылки шапки и боковые точки используют тот же переход. Карусель работ остаётся отдельной горизонтальной прокручиваемой областью. Слайд этапов помещается в один viewport и не имеет внутренней вертикальной прокрутки. Визуальные полосы прокрутки скрыты; переходы ограничены временной блокировкой и числом слайдов.

## Данные и локализация

`src/entities/work/model/types.ts` содержит семь карточек работ. Первая карточка использует локализованные RU/EN-постеры Kate Kravchenko и отдельные внешние URL для preview при наведении/фокусе/выборе и полного видео по нажатию; вторая — локализованные внешние постеры Horeo («horeo RU.png» / «horeo EN.png»), названия «Хореография» / «Choreography» и отдельные URL preview `vo-pole-bereza-preview.mp4` и полного видео `vo-pole-bereza-full.mp4`. Эти объекты используют постоянные публичные URL только из выделенных путей `KPV/works/cover/` и `KPV/works/work-videos/` хранилища Timeweb S3, без подписанных URL; остальные пять постеров хранятся локально. Автоматический стартовый язык следует сохранённому выбору, иначе языку браузера (RU для `ru-*`, EN для остальных); системный язык используется и для выбора RU/EN-постера Kate и Horeo. Оригинальные PNG/MP4 в `Referens/` остаются неизменными. Внешние URL используются напрямую, а `WorkCard` и `WorkVideoPlayer` применяют Vite `BASE_URL` к локальным путям для GitHub Pages project subpath.

Очередь в `WorksSection` ждёт `loadeddata`/ошибку стартового Hero-видео (при отключённой анимации сигналит сразу), затем начинает загрузку доступных preview источников первых трёх карточек. Когда preview карточки с индексом `n` действительно начинает воспроизводиться, очередь запрашивает источник карточки `n + 3`; элементы без назначенного `previewVideoSrc` пропускаются. Preview без звука и не запускается при `prefers-reduced-motion: reduce`. Плеер измеряет `videoWidth / videoHeight` из metadata, подстраивает ширину viewport и fullscreen под исходное соотношение сторон; до metadata используется `videoAspectRatio` карточки, если он указан.

Нажатие/Enter на карточке открывает портал-плеер; если `videoSrc` не задан, он показывает локализованную заглушку, а медиаконтролы отключены. Плеер обрабатывает play/pause, ±10 секунд, seek, громкость/mute и fullscreen; на широких экранах ряд упорядочен как play/seek, кнопка громкости, время, fullscreen. На мобильных нижняя кнопка play/pause скрыта, тап по видеокадру переключает воспроизведение, а ползунок громкости раскрывается вертикально от кнопки при наведении/нажатии и закрывается повторным нажатием или тапом вне. Space и M управляют воспроизведением и звуком при открытом плеере; громкость, mute и последний ненулевой уровень сохраняются в `localStorage`. Плеер закрывается крестиком, Escape или кликом по backdrop. RU/EN подписи находятся в словаре i18n.

Массив `STAGES_LIST` и модель этапа находятся в `src/entities/stage/`. `StagesSection` делит этапы на «До монтажа» и «Монтаж и постобработка»; девять компактных карточек закрыты по умолчанию, один пункт раскрывается по нажатию/клавиатуре и показывает описание с примечанием. При высоте до 700 px раскрытая карточка позиционируется поверх приглушённой сетки, чтобы сохранить один экран без внутренней прокрутки. Все подписи локализуются через типизированный `useI18n()`.

## Ресурсы и стили

- Цветовые и типографические токены: `src/shared/styles/variables.css`.
- Файлы локальных шрифтов находятся в `public/fonts/`. Первые две гарнитуры предварительно загружаются в `index.html`; встроенные `@font-face` используют относительные URL, чтобы сохранить работу в GitHub Pages project subpath. Storybook подключает шрифты через `.storybook/preview-head.html` и `public/fonts/font-faces.css`.
- Адаптивные правила секций: CSS Modules соответствующих виджетов и `shared/ui/section/`.
- Фокус и reduced motion задаются глобально; интерактивные элементы остаются управляемыми с клавиатуры и сенсорного экрана.
