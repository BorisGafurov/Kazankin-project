# Разработка и проверки

## Команды проекта

```bash
npm install
npm run dev                 # локальный Vite-сервер на порту 3000
npm run type-check          # TypeScript без генерации сборки
npm run build               # TypeScript + production-сборка Vite
npm run preview             # локальный просмотр production-сборки
npm run storybook           # Storybook на порту 6006
npm run build-storybook     # статическая сборка Storybook
```

В `package.json` нет отдельной команды unit/e2e-тестов. Не объявлять проверку типов или сборку заменой браузерного тестирования.

## Проверки интерфейса

1. **TypeScript и сборка:** `npm run type-check`, затем `npm run build`; ошибок и отсутствующих локальных ресурсов быть не должно.
2. **Storybook:** `npm run build-storybook` — проверка сборки существующих историй UI.
3. **RU/EN:** переключить язык и проверить Hero, а при чистой загрузке/обновлении — подпись заставки «Видеомонтаж» / «Video edit» с учётом сохранённого языка или языка браузера; также проверить загрузку всех семи обложек, названия «Хореография» / «Choreography», моковую метку/оценку 5/5, заголовки и детали девяти этапов, статусы, callout, контактный экран, навигацию и футер.
4. **Слайдовая прокрутка:** проверить колесо мыши, клавиши Arrow/Page/Space, touch-жест, ссылки шапки и SideDots. Навигация должна останавливаться на первом/последнем слайде; Space вне плеера продолжает обычную навигацию, пока открытый плеер перехватывает эту клавишу.
5. **Этапы:** проверить, что все девять карточек помещаются без вертикального скролла и обрезания на 320×568, 390×667 и desktop viewport; кнопка мыши/клавиатуры раскрывает одну карточку, а повторное нажатие той же кнопки с иконкой «×» закрывает её или переключает на другую. Escape закрывает активную панель; если поверх этапа открыто мобильное меню, первый Escape закрывает только меню. Клик по затемнённому фону вне панели закрывает её плавным fade, не блокируя открытие другой карточки. Детали должны появляться и исчезать через opacity без вертикального сдвига карточек; фон затемняется, выбранная карточка остаётся над затемняющим слоем. При высоте до 700 px подробности должны открываться центральной панелью, полностью оставаться видимыми и плавно исчезать при закрытии или клике по backdrop вне панели.
6. **Обложки:** в production preview проверить успешные загрузки локальных постеров и внешних RU/EN PNG Kate и Horeo; при переключении языка обложка Horeo должна меняться с `horeo RU.png` на `horeo EN.png` и обратно. Для GitHub Pages URL локальных изображений должен оставаться внутри `/Kazankin-project/images/works/`, не `/images/works/` у домена; внешние URL не должны получать префикс `BASE_URL`.
7. **Видеоплеер и preview работ:** мышью и клавишей Enter открыть карточку; проверить fade, порядок контролов, крестик/backdrop/Escape и возврат фокуса. В области видео кнопка Play видна, когда ролик остановлен; при воспроизведении Pause появляется при наведении и плавно исчезает через 1,5 секунды после ухода курсора. Проверить повторное наведение до истечения задержки. На мобильных ширинах 320 и 390 px нижняя Play/Pause отсутствует, панель и все оставшиеся контролы полностью помещаются по ширине; тап по видеокадру запускает или приостанавливает ролик. Кнопка громкости раскрывает ползунок вертикально при hover/focus или тапе; повторное нажатие и тап вне ползунка закрывают его без переполнения панели. При горизонтальном и вертикальном исходнике проверить, что viewport и fullscreen сохраняют `videoWidth / videoHeight` без чёрных полос. Space внутри плеера переключает play/pause, M переключает mute; эти клавиши не должны менять слайд. Изменить громкость и mute, закрыть и повторно открыть плеер либо перезагрузить сайт: оба аудиопараметра и предыдущий ненулевой уровень должны сохраниться; при недоступном localStorage интерфейс не должен падать. Убедиться, что открытый плеер блокирует свайп, колесо и клавиатурное переключение слайдов. При отсутствии `videoSrc` обложка и локализованная заглушка видны, медиаконтролы и fullscreen отключены, кнопка закрытия доступна. Для Kate проверить доступность по постоянным публичным URL обеих локализованных PNG-обложек, preview `kate-kravchenko-preview.mp4` и полного ролика `vo-pole-bereza-full.mp4`; для Horeo — загрузку RU/EN PNG, названий в соответствующем языке, muted preview `vo-pole-bereza-preview.mp4` при hover/focus/выборе и запуск полного видео `vo-pole-bereza-full.mp4` в плеере. Внешние ресурсы используют постоянные URL без подписанных параметров только из разрешённых префиксов `KPV/works/cover/` и `KPV/works/work-videos/`. Hover/focus/выбор карточки Kate запускает отдельный muted preview. После готовности стартового Hero-видео проверить, что начинаются запросы доступных preview первых трёх карточек; при воспроизведении карточки `n` начинается запрос карточки `n + 3`. У карточек без `previewVideoSrc` запрос пропускается; при `prefers-reduced-motion: reduce` autoplay preview отсутствует.
8. **Адаптивность:** проверить ширины 320, 390, 768, 1024 и 1440 px; искать обрезанный контент и горизонтальный overflow. Особое внимание — невысоким мобильным экранам, плееру, меню шапки и боковым точкам.
9. **Доступность:** проверить клавиатурный фокус, Escape-закрытие плеера/этапов/мобильного меню, возврат фокуса на исходную работу и кнопку меню, ловушку Tab в плеере, локализованные ARIA-подписи заставки и интерфейса, контраст и `prefers-reduced-motion`.
10. **Hero-видео и заставка:** на desktop загружается `hero-desktop.mp4`, на ширине до 767 px — `hero-mobile.mp4` с внешнего S3 URL; проверьте успешный HTTP-ответ и воспроизведение в production preview. Локальные видеофайлы не должны находиться в `public/` или входить в Git. На чистой загрузке проверьте порядок заставки: логотип, завершение раскрытия красной линии, затем вертикальное раскрытие подписи сверху вниз; подпись «Видеомонтаж» / «Video edit» должна оставаться на заставке, не под нижней строкой слогана Hero. При `prefers-reduced-motion: reduce` заставка показывается без анимации, с видимой подписью. При переходе с Hero элемент остаётся в DOM, видео ставится на паузу и не продвигает текущую позицию; при возврате воспроизведение продолжается с неё. Готовность первого кадра Hero-видео открывает очередь preview-префетча; при `prefers-reduced-motion: reduce` Hero-видео не создаётся, и очередь получает сигнал без него.
11. **Сохранность источников:** `Referens/` и `HighGrade-main/` должны оставаться без изменений.

## Примечание о требованиях

Код текущей страницы, включая эту локализацию стартовой заставки и удаление подписи из Hero, изменён напрямую по явному запросу владельца, без доступного High Grade CLI. Контракт `specs/changes/HG-0001/spec.json` и реестр High Grade не синхронизировались. Перед следующей формальной задачей сверить текущую реализацию с контрактом штатным совместимым маршрутом.
