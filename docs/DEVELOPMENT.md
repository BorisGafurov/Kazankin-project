# Разработка и проверки

## Команды проекта

```bash
npm install
npm run dev                 # локальный Vite-сервер на порту 3000
npm run type-check          # TypeScript без генерации сборки
npm run build               # TypeScript + production-сборка Vite
npm run preview             # локальный просмотр production-сборки
npm run storybook           # Storybook на порту 6006
npm run build-storybook     # статическая сборка Storybook
```

В `package.json` нет отдельной команды unit/e2e-тестов. Не объявлять проверку типов или сборку заменой браузерного тестирования.

## Проверки интерфейса

1. **TypeScript и сборка:** `npm run type-check`, затем `npm run build`; ошибок и отсутствующих локальных ресурсов быть не должно.
2. **Storybook:** `npm run build-storybook` — проверка сборки существующих историй UI.
3. **RU/EN:** переключить язык и проверить Hero, загрузку всех семи обложек, моковую метку/оценку 5/5, заголовки и детали девяти этапов, статусы, callout, контактный экран, навигацию и футер.
4. **Слайдовая прокрутка:** проверить колесо мыши, клавиши Arrow/Page/Space, touch-жест, ссылки шапки и SideDots. Навигация должна останавливаться на первом/последнем слайде; Space вне плеера продолжает обычную навигацию, пока открытый плеер перехватывает эту клавишу.
5. **Этапы:** проверить, что все девять карточек помещаются без вертикального скролла и обрезания на 320×568, 390×667 и desktop viewport; кнопка мыши/клавиатуры раскрывает одну карточку, а повторное нажатие той же кнопки с иконкой «×» закрывает её или переключает на другую. Escape закрывает активную панель; если поверх этапа открыто мобильное меню, первый Escape закрывает только меню. Клик по затемнённому фону вне панели закрывает её плавным fade, не блокируя открытие другой карточки. Детали должны появляться и исчезать через opacity без вертикального сдвига карточек; фон затемняется, выбранная карточка остаётся над затемняющим слоем. При высоте до 700 px подробности должны открываться центральной панелью, полностью оставаться видимыми и плавно исчезать при закрытии или клике по backdrop вне панели.
6. **Обложки:** в production preview проверить, что JPEG-запросы для семи карточек завершаются успешно. Для GitHub Pages URL должен оставаться внутри `/Kazankin-project/images/works/`, не `/images/works/` у домена.
7. **Видеоплеер работ:** мышью и клавишей Enter открыть карточку; проверить fade, порядок однострочных контролов (play/±10, громкость, время, fullscreen), уменьшенную высоту панели, крестик/backdrop/Escape и возврат фокуса. Space внутри плеера переключает play/pause, M переключает mute; эти клавиши не должны менять слайд. Изменить громкость и mute, закрыть и повторно открыть плеер либо перезагрузить сайт: оба аудиопараметра и предыдущий ненулевой уровень должны сохраниться; при недоступном localStorage интерфейс не должен падать. Убедиться, что открытый плеер блокирует свайп, колесо и клавиатурное переключение слайдов. При отсутствии `videoSrc` обложка и локализованная заглушка видны, медиаконтролы и fullscreen отключены, кнопка закрытия доступна. После добавления ролика проверить play/pause, seek, ±10 секунд, mute/громкость, длительность и fullscreen.
8. **Адаптивность:** проверить ширины 320, 390, 768, 1024 и 1440 px; искать обрезанный контент и горизонтальный overflow. Особое внимание — невысоким мобильным экранам, плееру, меню шапки и боковым точкам.
9. **Доступность:** проверить клавиатурный фокус, Escape-закрытие плеера/этапов/мобильного меню, возврат фокуса на исходную работу и кнопку меню, ловушку Tab в плеере, локализованные ARIA-подписи, контраст и `prefers-reduced-motion`.
10. **Hero-видео:** на desktop загружается `hero-desktop.mp4`, на ширине до 767 px — `hero-mobile.mp4` с внешнего S3 URL; проверьте успешный HTTP-ответ и воспроизведение в production preview. Локальные видеофайлы не должны находиться в `public/` или входить в Git. Фон размыт, затемнён и не перекрывает текст; при переходе с Hero видео удаляется из DOM, а при `prefers-reduced-motion: reduce` не создаётся.
11. **Сохранность источников:** `Referens/` и `HighGrade-main/` должны оставаться без изменений.

## Примечание о требованиях

Код текущей страницы был изменён напрямую по явному запросу владельца, без High Grade CLI. Контракт `specs/changes/HG-0001/spec.json` и реестр High Grade в этой правке не синхронизировались. Перед следующей формальной задачей сверить текущую реализацию с контрактом штатным совместимым маршрутом.
