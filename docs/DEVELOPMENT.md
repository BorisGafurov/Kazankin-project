# Инструкция разработчика (DEVELOPMENT)

В этом документе описаны команды локального запуска, разработки компонентов в Storybook, проверки качества, архитектурных регламентов FSD и тестирования адаптивности.

---

## 1. Стек и скрипты проекта

Проект базируется на React, TypeScript, CSS Modules, Storybook и Motion:

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера локальной разработки
npm run dev

# Запуск Storybook для изолированной разработки UI-компонентов
npm run storybook

# Сборка Storybook в статический каталог
npm run build-storybook

# Проверка типов TypeScript
npm run type-check

# Сборка production-бандла
npm run build

# Локальный предпросмотр production-сборки
npm run preview
```

---

## 2. Архитектурные правила Feature-Sliced Design (FSD)

1. **Импорты только сверху вниз:**
   `app` → `pages` → `widgets` → `features` → `entities` → `shared`.
   *Слой `shared` не может импортировать ничего из слоёв выше.*
2. **Публичный API каждого слайса:**
   Каждый слайс или сегмент экспортирует наружу сущности исключительно через корневой `index.ts`.
3. **Лейаут-компоненты:**
   При создании любого UI-элемента в `widgets` или `features` используйте примитивы из `@shared/ui` (`Container`, `Section`, `Heading`, `Text`, `Block`, `Stack`, `Grid`).

## 3. Матрица адаптивности и разрешений (Responsive Matrix)

При проверке интерфейса обязательно тестируются следующие типовые разрешения:

| Устройство | Разрешение | Поведение интерфейса |
|---|---|---|
| **Compact Mobile (iPhone SE)** | `320px – 375px` | 1 колонка, отступы 16px, бургер-меню, fluid font size через `clamp()`, `min-height: 100dvh` |
| **Standard Mobile (iPhone 14/15)** | `390px – 430px` | 1 колонка, тач-таргеты 44px+, бургер-меню, безопасный скролл без обрезания |
| **Tablet Portrait (iPad)** | `768px – 834px` | 2 колонки для работ и отзывов, компактная навигация, отсутствие overflow-x |
| **Tablet Landscape / Laptop** | `1024px – 1280px` | Полноэкранный snap-scroll, десктопное меню шапки с активным Scroll-Spy |
| **Desktop / 4K** | `1440px – 2560px` | 3 колонки для работ, центрированный контейнер max-width 1200px |

## 4. Матрица проверок (Check Matrix)

Перед завершением любой задачи по методологии High Grade выполняются следующие проверки:

| Проверка | Команда / Метод | Критерий успеха |
|---|---|---|
| **TypeScript** | `npm run type-check` | 0 ошибок типизации |
| **Storybook** | `npm run build-storybook` | Все истории примитивов из `@shared/ui` собираются без ошибок |
| **CSS-переменные** | Аудит стилей | Отсутствие «сырых» hex/px значений вне `:root` |
| **SEO & a11y** | Lighthouse / Axe | Доступность для скринридеров (ARIA, focus-visible), корректные теги `h1-h6` |
| **Мобильная адаптивность** | DevTools Device Mode (320px–768px) | 0 горизонтального скролла, тач-таргеты 44px+, рабочее бургер-меню |
| **i18n** | Проверка локализации | 100% покрытие текстов на RU и EN, включая отзывы и этапы |
| **Scroll & Nav** | Ручной / e2e тест | Плавный полноэкранный переход между секциями, подсветка активного пункта в шапке |
| **Аккордеон** | Ручной / e2e тест | Клик по этапу плавно раскрывает детальное описание и обновляет `aria-expanded` |
| **Отзывы** | Рендер-тест | Корректный вывод звёздного рейтинга (1–5) и текста |
