# Разработка и проверки

## Команды проекта

```bash
npm install
npm run dev                 # локальный Vite-сервер на порту 3000
npm run type-check          # TypeScript без генерации сборки
npm run build               # TypeScript + production-сборка Vite
npm run preview             # локальный просмотр production-сборки
npm run storybook           # Storybook на порту 6006
npm run build-storybook     # статическая сборка Storybook
```

В `package.json` нет отдельной команды unit/e2e-тестов. Не объявлять проверку типов или сборку заменой браузерного тестирования.

## Проверки интерфейса

1. **TypeScript и сборка:** `npm run type-check`, затем `npm run build`; ошибок и отсутствующих локальных ресурсов быть не должно.
2. **Storybook:** `npm run build-storybook` — проверка сборки существующих историй UI.
3. **RU/EN:** переключить язык и проверить Hero, все семь карточек работ, заголовки и описания девяти этапов, статусы, callout, контактный экран, навигацию и футер.
4. **Слайдовая прокрутка:** проверить колесо мыши, клавиши Arrow/Page/Space, touch-жест, ссылки шапки и SideDots. Навигация должна останавливаться на первом/последнем слайде.
5. **Вложенная прокрутка:** в секции этапов длинный контент прокручивается внутри экрана; переход к следующему слайду происходит только когда внутреннюю область больше нельзя прокручивать в этом направлении. Карусель работ не должна перехватывать вертикальное переключение.
6. **Адаптивность:** проверить ширины 320, 390, 768, 1024 и 1440 px; искать обрезанный контент и горизонтальный overflow. Особое внимание — невысоким мобильным экранам, меню и боковым точкам.
7. **Доступность:** проверить клавиатурный фокус, доступные подписи навигации/кнопок, контраст на трёх фонах и `prefers-reduced-motion`.
8. **Сохранность источников:** `Referens/` и `HighGrade-main/` должны оставаться без изменений.

## Примечание о требованиях

Код текущей страницы был изменён напрямую по явному запросу владельца, без High Grade CLI. Контракт `specs/changes/HG-0001/spec.json` и реестр High Grade в этой правке не синхронизировались. Перед следующей формальной задачей сверить текущую реализацию с контрактом штатным совместимым маршрутом.
