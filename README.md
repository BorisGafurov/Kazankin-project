> Локация: **Саратов · удалённо**.  
> Языки: **Русский / English** (полная двуязычность).

---

## Архитектура и стек технологий

Проект разработан по методологии **Feature-Sliced Design (FSD)**:

- **Frontend:** React + React Router + TypeScript
- **Стилизация:** CSS Modules + `clsx`
- **Дизайн-система:** Строгие CSS-переменные в `:root` (все цвета, отступы, типографика без исключения)
- **Компонентная модель:** Атомарные лейаут-примитивы (`Container`, `Section`, `Heading`, `Text`, `Block`, `Stack`, `Grid`)
- **UI-документация:** Storybook для изолированной разработки и тестирования компонентов
- **Анимации:** Motion (Framer Motion) для плавных переходов и раскрытия аккордеонов
- **Локализация:** Двуязычный модуль (RU / EN) с мгновенным синхронным переводом всего контента, включая отзывы
- **Навигация и скролл:**
  - Полноэкранный переход по секциям (Fullpage Snap Scroll 100vh)
  - Фиксированная шапка сайта (`position: fixed`) со Scroll-Spy индикацией текущей категории

## Категории и функционал сайта

1. **Главный экран (Hero):**
   - Название бренда: `KAZANKIN` / `ВИДЕОМОНТАЖ & SMM`
   - Главный заголовок: **«ВАШИ КАДРЫ. ЦЕЛЬНАЯ ИСТОРИЯ.»**
   - Кнопки быстрого перехода: `Смотреть работы ↗`, `Обсудить проект →`
   - Слоган: *«ВЫ СНИМАЕТЕ. Я СОБИРАЮ ИСТОРИЮ.»*

2. **Работа (Портфолио):**
   - Заголовок: **«СНАЧАЛА — ВПЕЧАТЛЕНИЕ.»**
   - Сетка видео- и визуальных кейсов (постеры, типографика, категории, превью).

3. **Этапы (Процесс работы):**
   - Заголовок: **«ГДЕ Я МОГУ ВАМ ПОМОЧЬ»**
   - **Интерактивный аккордеон:** карточки этапов кликабельны и плавно раскрываются, показывая подробный состав работ, условия, сроки и рекомендации.
   - Статусные бейджи: *«✓ Беру на себя»*, *«По договорённости»*, *«Помогаю»*, *«— Не выполняю»*.

4. **Отзывы:**
   - Заголовок: **«ОТЗЫВЫ КЛИЕНТОВ»**
   - Карточки с оценкой по **5-балльной системе** (интерактивный рендер 1–5 звёзд), именем заказчика, названием проекта и развёрнутым текстом отзыва.
   - Полный перевод всех отзывов на английский язык при переключении локали.

5. **Связаться:**
   - Заголовок: **«ЕСТЬ МАТЕРИАЛ? ЕСТЬ ИДЕЯ?»**
   - Контакты, ссылки на Telegram, WhatsApp, email и форма быстрого обращения.

6. **Подвал (Footer):**
   - Копирайт, локация: *«Саратов · удалённо»*, навигационные ссылки.

## Дизайн-система и цветовые токены

Палитра строго соответствует спецификации из [Referens/photo_2026-11-13_00-34-23_254480.jpg](Referens/photo_2026-11-13_00-34-23_254480.jpg):

| `--color-warm-black` | `#100D0C` | Тёмные секции (Hero, блок контактов), подложки |
| `--color-milk` | `#F3EFE7` | Основной светлый фон страницы (блоки Работа, Этапы, Отзывы) |
