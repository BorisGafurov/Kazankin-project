# KAZANKIN — видеомонтаж

**Сайт-портфолио Дмитрия Казанкина.** Актуальная версия показывает видеомонтаж и постобработку, подбор работ и путь от идеи до готового ролика.

> Ваши кадры. Цельная история.<br>
> Саратов · удалённо · RU / EN

## Структура страницы

Лендинг состоит из пяти полноэкранных слайдов:

1. **Главный экран:** позиционирование, переход к работам и контактам; декоративный размытый видеофон загружает отдельные версии роликов для desktop и mobile из внешнего объектного хранилища. Видео не хранятся в репозитории.
2. **Работы:** горизонтально прокручиваемые карточки с семью предоставленными обложками/визуальными концепциями. Обложки Kate Kravchenko и Horeo локализуются RU/EN; они, а также preview и полное видео загружаются по постоянным публичным URL Timeweb без подписанных параметров; разрешены только пути `KPV/works/cover/` и `KPV/works/work-videos/`. Остальные пять постеров остаются локальными. Нажатие или Enter на карточке открывает модальный плеер с fade-анимацией, крестиком и закрытием по клику вне окна/Escape; панель управления слегка перекрывает видеокадр. На широких экранах ряд содержит play/seek, кнопку громкости, время и fullscreen; на мобильных нижняя Play/Pause скрыта, а тап по самому видео переключает воспроизведение. Ползунок громкости раскрывается вертикально от кнопки динамика при наведении или нажатии и закрывается повторным нажатием либо тапом вне него. Space переключает play/pause, M — mute; громкость и mute-состояние сохраняются локально. Пока источники видео не добавлены, показывается обложка и сообщение-заглушка, а функции воспроизведения/перемотки/звука отключены. Стрелки карусели по-прежнему только меняют выбранную работу.
3. **Отзывы:** отдельная категория с одним двуязычным моковым примером и оценкой по шкале 1–5. Карточка явно помечена как демонстрационная, не настоящий отзыв; после получения материалов её заменим.
4. **Этапы:** девять карточек-аккордеонов в группах до монтажа и в монтаже/постобработке. Карточки помещаются на один экран; нажатие раскрывает детали одного этапа поверх сетки и плавно затемняет фон, не сдвигая другие карточки. На невысоких экранах детали открываются центральной панелью поверх приглушённой сетки, не добавляя прокрутку. В отдельной плашке отмечено, что съёмка остаётся на стороне клиента, а с подготовкой материалов можно помочь.
5. **Контакт:** короткий призыв обсудить задачу и ссылка для связи.

Слайдовая прокрутка сохранена: колесо мыши, вертикальный свайп, клавиши навигации, ссылки шапки и боковые индикаторы меняют активный экран. Этапы не прокручиваются внутри: все пункты помещаются в viewport, а подробности раскрываются поверх сетки; на низких экранах выбранная карточка открывается центральной панелью. Карусель работ сохраняет отдельную горизонтальную прокрутку. Видимые полосы прокрутки скрыты.

Съёмку выполняет клиент или его оператор. Текущая версия сайта фокусируется на монтаже и постобработке; другие направления в интерфейсе сейчас не заявлены.

## Визуальная система

Палитра следует `Referens/colors.jpg`: тёплый чёрный `#100D0C`, молочный `#F3EFE7`, глубокий бордовый `#57191D`, светлый бежевый `#D1B39C`, тёмный текст `#211D1A`, серо-коричневый `#766D64` и линия `#C8BDB0`. Бордовый применяется как акцент и как фон финального контактного слайда по последнему макету.

Сайт использует локальные шрифты из `public/fonts/`: Druk Wide Cyr, Druk Text Wide Cyr и FindSansPro. Лицензия и уведомление FindSansPro сохранены рядом с файлами шрифта.

## Технологии и запуск

Проект использует React 18, TypeScript, Vite, CSS Modules, Feature-Sliced Design, Storybook и локальный модуль RU/EN.

```bash
npm install
npm run dev
npm run type-check
npm run build
npm run storybook
npm run build-storybook
```

## Статус требований

По отдельному прямому разрешению владельца раздел «Отзывы» добавлен третьим экраном после портфолио; всего активных слайдов теперь пять. До получения материалов там отображается только честное RU/EN-сообщение. Нативная спецификация [HG-0001](specs/changes/HG-0001/spec.json) и её реестр не менялись и не синхронизированы с текущей композицией. Перед следующей формальной задачей контракт нужно согласовать и синхронизировать штатным совместимым инструментом.
