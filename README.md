# KAZANKIN — видеомонтаж

**Сайт-портфолио Дмитрия Казанкина.** Актуальная версия показывает видеомонтаж и постобработку, подбор работ и путь от идеи до готового ролика.

> Ваши кадры. Цельная история.<br>
> Саратов · удалённо · RU / EN

## Структура страницы

Лендинг состоит из четырёх полноэкранных слайдов:

1. **Главный экран:** позиционирование, переход к работам и контактам.
2. **Работы:** горизонтально прокручиваемые карточки с семью предоставленными обложками/визуальными концепциями из `Referens/Cover/`.
3. **Этапы:** девять статичных карточек, сгруппированных до монтажа и в монтаж/постобработку. В отдельной плашке отмечено, что съёмка остаётся на стороне клиента, а с подготовкой материалов можно помочь.
4. **Контакт:** короткий призыв обсудить задачу и ссылка для связи.

Слайдовая прокрутка сохранена: колесо мыши, вертикальный свайп, клавиши навигации, ссылки шапки и боковые индикаторы меняют активный экран. Длинный экран этапов сохраняет внутреннюю вертикальную прокрутку; она не должна принудительно переключать слайд, пока внутри есть доступное содержимое.

Съёмку выполняет клиент или его оператор. Текущая версия сайта фокусируется на монтаже и постобработке; другие направления в интерфейсе сейчас не заявлены.

## Визуальная система

Палитра следует `Referens/colors.jpg`: тёплый чёрный `#100D0C`, молочный `#F3EFE7`, глубокий бордовый `#57191D`, светлый бежевый `#D1B39C`, тёмный текст `#211D1A`, серо-коричневый `#766D64` и линия `#C8BDB0`. Бордовый применяется как акцент и как фон финального контактного слайда по последнему макету.

Сайт использует локальные шрифты из `public/fonts/`: Druk Wide Cyr, Druk Text Wide Cyr и FindSansPro. Лицензия и уведомление FindSansPro сохранены рядом с файлами шрифта.

## Технологии и запуск

Проект использует React 18, TypeScript, Vite, CSS Modules, Feature-Sliced Design, Storybook и локальный модуль RU/EN.

```bash
npm install
npm run dev
npm run type-check
npm run build
npm run storybook
npm run build-storybook
```

Подробности: [архитектура](docs/ARCHITECTURE.md), [дизайн-система](docs/DESIGN_SYSTEM.md), [разработка и проверки](docs/DEVELOPMENT.md).

## Статус требований

По прямому запросу владельца страницы код обновлён напрямую, без High Grade CLI. Нативная спецификация [HG-0001](specs/changes/HG-0001/spec.json) и её реестр намеренно не менялись: перед следующей спецификационной задачей актуальную реализацию и контракт нужно согласовать и синхронизировать штатным совместимым инструментом.
